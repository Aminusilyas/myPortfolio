# Aminu — Personal Portfolio

Simple responsive portfolio with four pages: `index.html`, `about.html`, `projects.html`, and `contact.html`.

How to view:

1. Open `index.html` in your browser (double-click or use Live Server).

Notes:
- The contact form uses a `mailto:` fallback (no backend).
- Assets are in `assets/css` and `assets/js`.
 - To add your photo, place an image named `profile.jpg` in `assets/images/` (1500×900 or square works). The site will use `assets/images/profile.jpg` and falls back to a placeholder if the file is missing.
